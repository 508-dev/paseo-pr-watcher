PR watcher keeps a selected Paseo agent aware of its GitHub pull request after the agent finishes. Enroll a PR from that agent's chat with `/watch-pr https://github.com/owner/repo/pull/123`. The plugin checks for newly failing checks, submitted reviews, and merge conflicts every two minutes, then sends a bounded follow-up to the same agent. A Watch list in Command Center shows active watches, errors, and delivery state on desktop and mobile.

The daemon machine needs the GitHub CLI (`gh`) installed and authenticated with access to the watched repositories. Watching is opt-in per PR. The plugin reads PR status, checks, and reviews through `gh pr view`; it sends the relevant events to the selected Paseo agent. It stores watch state on the daemon machine at `$PASEO_HOME/plugins/pr-watcher-state.json`, or at `~/.paseo/plugins/pr-watcher-state.json` when `PASEO_HOME` is unset. Set `PASEO_PR_WATCHER_STATE_FILE` to use another location.

Existing failures and reviews form the initial baseline. The plugin wakes the agent only for later changes. It waits at least ten minutes between follow-ups and pauses after five. If delivery is uncertain, it stops automatic sends and asks you to inspect the chat before retrying or marking the event handled. A closed PR stops its watch. The plugin requires Paseo 0.16.0 beta 1 or newer within the 0.16 series, including a compatible app client.
